01

Translated page addresses (URLs)

Good news: with Polylang, each language version of a page gets its own address in its own language, for example:

  • Englishu-teal.com/about/
  • Germanu-teal.com/de/ueber-mich/

This works for all main pages, landing pages, legal pages and each individual case study, all in the free version of Polylang.

One exception: the Case Studies section

With the free version, the fixed part of the address in front of each case study stays the same in every language:

Free Polylang Polylang Pro
English /case-studies/project-name/ /case-studies/project-name/
German /de/case-studies/projekt-name/ /de/fallstudien/projekt-name/

Both options work fine for Google. Pro only changes how the address looks in German (and later Spanish). Polylang Pro is licensed per website with a yearly renewal for updates and support. We'll confirm the exact price with you before buying anything.
