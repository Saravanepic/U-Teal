6. Information for your privacy policy (T1)

Here is how the website will work technically, so your legal-text provider can phrase the privacy policy. This is a technical description, not legal advice. We'll confirm the exact settings (marked "to confirm") when we build the site.

  • Hosting: the website runs on Hostinger, in an EU data centre. Like every web server, it keeps short technical log files (IP address, date and time, page, browser) for security. You need Hostinger's data processing agreement (DPA); Hostinger provides it for its customers.
  • Analytics (Matomo): Matomo runs inside your WordPress, so the data stays on your own server and isn't shared with anyone. It works without cookies, and IP addresses are shortened (the last two parts are removed) before they are stored. It records which pages are visited, when, from which website visitors came, browser / device / operating system and the approximate country. Raw data is deleted after a set time (to confirm, e.g. 6 months). Matomo provides an opt-out box that we'll place in the privacy policy, and it respects "Do Not Track" browser settings.
  • Cookies: the website sets no cookies for visitors. We switch off the language cookie of Polylang (the language is part of the address, e.g. /de/). Only you, when logged in to WordPress, get the usual login cookies.
  • Fonts: the font (Manrope) is stored on your own server. There is no connection to Google Fonts or any other font service.
  • Pictures: all pictures, including the Unsplash photos, are stored on your server. No connection to Unsplash.
  • Contact form: name, email, organisation (optional) and message are sent by email to nadja@u-teal.com through Brevo (Sendinblue SAS, Paris, France; EU servers) and kept in WordPress as a copy (to confirm: keep or switch off, and for how long).
  • Spam protection (hCaptcha): the forms use hCaptcha by Intuition Machines, Inc. (USA). To check that a visitor is human, hCaptcha processes the IP address and browser data, which means a transfer to the USA. This needs a mention in the privacy policy. If you'd rather avoid any US provider, we can use only the invisible honeypot field (no third party); it catches most spam.
  • Newsletter (Brevo): email address only, with double opt-in (confirmation email). The data is stored by Brevo (EU). Brevo measures by default whether newsletters are opened and links clicked; this can be switched off in Brevo.
  • Booking (meetergo): the "Choose a time" button is a link to meetergo (Germany). Data is only processed by meetergo when someone opens the link and books.
  • LinkedIn: simple links, no LinkedIn plugins or buttons, so no data goes to LinkedIn unless someone clicks.
  • No embedded content: no YouTube videos, maps or social media feeds. If you add these later, the privacy policy and a cookie banner need to be updated (see T3).
